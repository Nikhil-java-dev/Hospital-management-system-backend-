# 🏥 Hospital Management System - Frontend

A modern Hospital Management System frontend built with React.js. The application enables doctors, patients, and administrators to manage appointments, profiles, medical notes, and healthcare workflows through an intuitive user interface.

## 🚀 Features

### 👨‍⚕️ Doctor Module

- Doctor Registration
- Doctor Profile Management
- View Appointments
- Create Medical Notes
- Manage Availability

### 🧑 Patient Module

- Patient Profile Management
- Book Appointments
- View Medical Reports
- Download PDF Reports

### 📅 Appointment Module

- Appointment Booking
- Doctor Selection
- Appointment History
- Date-wise Appointment Tracking

### 📝 Reports Module

- Doctor Notes
- PDF Generation using jsPDF
- Patient Medical Reports

### 🔔 User Experience

- Toast Notifications
- Responsive Design
- Form Validation
- Dynamic Routing
- Reusable Components

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Nikhil-java-dev/Hospital-management-system-frontend.git
```

### Navigate to Project

```bash
cd Hospital-management-system-frontend
```

### Install Dependencies

```bash
npm install
```

### Run Application

```bash
npm run dev
```

Frontend will start on:

```bash
http://localhost:5173
```

---

## 🔗 Backend Connection

Make sure the backend server is running:

```bash
http://localhost:8090
```
